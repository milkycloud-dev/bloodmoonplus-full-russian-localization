## English

### Overview

This repository provides clean, standalone Russian localization files for **BloodMoonPlus v1.0.1**.
It contains only configuration and text files to respect original author licensing and copyright requirements.

### Files

- `locales/ru.yml`: Complete Russian translation for all 105 locale keys.
- `locales/locales.yml`: Locale selector configured to `ru`.
- `messages.yml`: Russian fallback messages.
- `bosses.yml`: Localized boss names and titles.
- `items.yml`: Localized custom weapons, armor, and lore.
- `loot.yml`: Localized rarity display names.

### Installation

1. Copy configuration files into `plugins/BloodMoonPlus/`.
2. In `plugins/BloodMoonPlus/locales/locales.yml` verify `Language: ru`.
3. Run `/luna reload` or restart your server.

## Русский

### Описание

Репозиторий содержит чистые файлы русской локализации для **BloodMoonPlus v1.0.1**.
В состав включены исключительно файлы конфигурации и переводов, без бинарных сборок, с соблюдением требований лицензий авторов.

### Файлы

- `locales/ru.yml`: Полный перевод всех 105 ключей локали на русский язык.
- `locales/locales.yml`: Переключатель языка настроен на `ru`.
- `messages.yml`: Резервные сообщения на русском языке.
- `bosses.yml`: Переведенные имена и титулы боссов.
- `items.yml`: Переведенные названия кастомного снаряжения и описания.
- `loot.yml`: Переведенные названия редкостей предметов.

### Установка

1. Скопируйте файлы конфигурации в папку `plugins/BloodMoonPlus/`.
2. В файле `plugins/BloodMoonPlus/locales/locales.yml` убедитесь в значении `Language: ru`.
3. Выполните команду `/luna reload` или перезапустите сервер.
