## English

### Overview

This repository provides clean, standalone Russian localization files for **BloodMoonPlus v1.0.1**.
It contains only configuration and text files to respect original author licensing and copyright requirements.

### Files

- `locales/ru.yml`: All 105 keys translated.
- `bosses.yml`, `items.yml`, `loot.yml`, `messages.yml`, `config.yml`.

### Installation

1. Copy configuration files into `plugins/BloodMoonPlus/`.
2. Or download pre-built `.jar` from [Releases](https://github.com/milkycloud-dev/bloodmoonplus-full-russian-localization/releases/latest).

### Releases

Pre-built ready-to-use binaries (`.jar` / `.zip`) are available for download in [Releases](https://github.com/milkycloud-dev/bloodmoonplus-full-russian-localization/releases/latest).

## Русский

### Описание

Репозиторий содержит чистые файлы русской локализации для **BloodMoonPlus v1.0.1**.
В состав включены исключительно файлы конфигурации и переводов, без бинарных сборок, с соблюдением требований лицензий авторов.

### Файлы

- `locales/ru.yml`: Все 105 ключей переведены.
- `bosses.yml`, `items.yml`, `loot.yml`, `messages.yml`, `config.yml`.

### Установка

1. Скопируйте файлы конфигурации в `plugins/BloodMoonPlus/`.
2. Либо скачайте готовую сборку `.jar` из раздела [Releases](https://github.com/milkycloud-dev/bloodmoonplus-full-russian-localization/releases/latest).

### Релизы

Готовые собранные бинарные пакеты (`.jar` / `.zip`) доступны для загрузки в разделе [Releases](https://github.com/milkycloud-dev/bloodmoonplus-full-russian-localization/releases/latest).
