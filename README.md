## English

### Overview

BloodMoonPlus is a dynamic blood moon event plugin for Paper, Spigot, and Purpur servers. It introduces terrifying nighttime events, custom blood mobs, bosses, and unique RPG loot. 

However, in production deployments, players frequently encountered visual rendering glitches in item tooltips, where color codes failed to parse and displayed raw characters (such as `&7Оружие древнего воителя.`).

This repository provides a production-ready Russian translation package and fixes the MiniMessage color code deserialization bug.

---

### Technical Deep-Dive: Color Parsing Bug & Solution

#### The Issue
When players inspect custom weapons and armor generated by the plugin (such as the Doom Sword / Меч погибели), the lore text in the item tooltip displays raw color codes like `&7` instead of rendering text in subtle gray.

#### Bytecode Root Cause Analysis
Disassembly of `dev.bloodmoonplus.Util.class` and its internal helper `legacyToMini(String)` revealed the core reason:
```java
public static String legacyToMini(String str) {
    if (str == null) return "";
    if (str.indexOf('§') < 0) {
        return str;
    }
    // Only section sign replacements are performed here:
    // replaces §0 -> <black>, §7 -> <gray>, etc.
    ...
}
```
In `ItemFactory.class`, item display names and lore descriptions are passed through `Util.item()` and `legacyToMini()`, which are then parsed by Adventure's MiniMessage engine (`MiniMessage.miniMessage().deserialize(...)`).

Because `legacyToMini()` explicitly checks for the section character `§` and immediately returns the unmodified string if no section sign exists, all strings using standard YAML ampersand color codes (`&7`) bypassed the converter completely. MiniMessage does not recognize `&` ampersands, resulting in literal, unformatted text on client screens.

#### The Fix
1. **Migration to MiniMessage Tags**: All 29 legacy color codes in `items.yml` lore were migrated to native `<gray>...</gray>` tags.
2. **Binary Packaging**: The corrected `items.yml` was repacked into the default assets inside `BloodMoonPlus-1.0.1-RU.jar`, ensuring that even upon first run or config resets, default items generate without color code artifacts.

### Protection Against Auto-Updaters

To ensure automated tools (like `vanilla-plugin-updater`) do not overwrite the patched jar or revert `items.yml` back to upstream templates:
1. Register `BloodMoonPlus` in the updater exclusion list (`IGNORE_DEFAULT` in `compose.yml`).
2. Set `"ignore": true, "auto": false` in `state.json`.

## Русский

### Описание

BloodMoonPlus добавляет на сервер атмосферные события кровавой луны, нашествия усиленных монстров, опасных процедурных боссов и кастомное RPG-снаряжение.

При использовании оригинальных конфигураций и сборок игроки сталкиваются с неприятным визуальным багом: во всплывающих подсказках (тултипах) кастомных предметов описания (lore) начинаются с сырых символов цветовых кодов, например `&7Оружие древнего воителя.` вместо серого текста.

Этот репозиторий содержит полную русскую локализацию всех компонентов плагина и устраняет баг парсинга цветов в MiniMessage.

---

### Подробный технический разбор: баг парсинга цветов и решение

#### В чем заключалась проблема
При наведении курсора на уникальные предметы плагина (например, «Меч погибели») нижняя строка описания предмета отображалась с видимым текстовым мусором: `&7Оружие древнего воителя.`.

#### Анализ байткода плагина
При декомпиляции класса `dev.bloodmoonplus.Util.class` был исследован метод `legacyToMini(String)`:
```java
public static String legacyToMini(String str) {
    if (str == null) return "";
    if (str.indexOf('§') < 0) {
        return str;
    }
    // Конвертируются только символы параграфа:
    // замена §0 -> <black>, §7 -> <gray> и т.д.
    ...
}
```
В классе создания предметов `ItemFactory.class` имя и lore предмета передаются через данный метод в парсер Adventure MiniMessage (`MiniMessage.miniMessage().deserialize(...)`).

Метод `legacyToMini` содержит явную оптимизацию: если в строке нет символа `§`, он мгновенно возвращает исходную строку без изменений. Традиционные цветовые коды с амперсандом (`&7`), прописанные в конфигурации `items.yml`, вообще не подвергались конвертации. MiniMessage не считает символ `&` служебным тегом цвета и выводит его игроку как обычный текст.

#### Как это исправлено
1. **Перевод на теги MiniMessage**: В `items.yml` все 29 вхождений устаревшего кода `&7` заменены на нативный тег `<gray>...</gray>`.
2. **Пересборка бинарного пакета**: Исправленный файл `items.yml` зашит внутрь jar-архива `BloodMoonPlus-1.0.1-RU.jar`. При первой инициализации или восстановлении файлов плагин создает корректную конфигурацию без артефактов.

### Расширенные механики и возможности (v1.0.5)

- **Разновидности Луны (`blood`, `black`, `purple`)**:
  - Классическая Кровавая Луна, Чёрная Луна (тьма, увеличенное на 50% здоровье и урон монстров, фиолетовый боссбар), Фиолетовая Луна (астральные частицы порталов и дыхания дракона, +30% характеристик, +25% скорости).
  - Быстрый запуск: `/luna black [длительность] [сложность] [мир]`, `/luna purple`, `/luna blood` (с русскими алиасами `черная`, `фиолетовая`, `кровавая`).
- **Безопасные для карты боссы в обычном мире**:
  - **Чёрный Дракон Края (`dragon_negro`)**: Агрессивный дракон, охотящийся за игроками в обычном мире без разрушения блоков.
  - **Теневой Исушитель (`wither_sombra`)**: 3 активные головы, залповый огонь черепами, активное преследование по воздуху и взрывная ударная волна (способность `EXPLODE`) со 100% гарантией **нулевого разрушения блоков** (очистка `blockList()`, отмена `EntityChangeBlockEvent`, запрет огня от взрывов).
  - **Призыв боссов вне Кровавой Луны**: Команда `/luna boss <id> [мир|игрок]` работает в любое время, даже если луна не активна. Поддерживается полное автодополнение Tab для ID боссов, игроков и миров.
- **Динамическая сложность и анти-кемпинг**:
  - Увеличение сложности (+0.25x каждые 25 сек до x5.0) и призыв карательных орд при отсиживании в бункерах дольше 45 секунд.
  - Кара измерений (Dimension Wrath в Незере и Крае) и Кара элитр (Elytra Wrath при парении на высоте выше Y=90).
- **Три типа предупреждений и атмосферный таймер**:
  - `/luna warn <время> [normal|dangerous|lethal] [тип_луны] [start]` с атмосферными градиентными оповещениями и звуками.
  - Режим одиночного предупреждения (`countdown.periodic-alerts: false`) без спама в чат.
- **Блокировка режима наблюдателя и иммунитет для OP**:
  - Игроки не могут переходить в режим Spectator во время луны.
  - Администраторы (OP) могут переходить в режим наблюдателя и полностью игнорируются мобами, боссами и системами кары.
